# Arena Pixel Client

Nuxt 4 + PixiJS-baserad arena pixelklient med interaktiva moduler, timeline och PWA-stöd.

## Utveckling

```bash
npm install
npm run dev
```

## Scripts

- `npm run build`
- `npm run preview`
- `npm run lint`
- `npm run format`
- `npm run test`

## Miljövariabler

Skapa `.env` med:

```
WS_URL=wss://example.com/show
SHOW_ID=demo
```

## Test

```bash
npm run test
```
